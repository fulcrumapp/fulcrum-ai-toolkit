# Solution Document Asset Index

| File | What it holds | Public source |
| --- | --- | --- |
| [`solution-one-pager-template.md`](solution-one-pager-template.md) | Audience, problem, solution, readiness, ownership, and handoff; save at an agreed path only when requested. | [Fulcrum developer documentation](https://docs.fulcrumapp.com/) |
| [`solution-share-summary.txt`](solution-share-summary.txt) | The short chat or email summary that accompanies the one-pager. | [Fulcrum developer documentation](https://docs.fulcrumapp.com/) |

Both templates use neutral placeholders for customers, partners, independent
builders, or internal teams. Internal product intake is optional and should
be omitted unless explicitly requested. Draft or save only within the user's
requested scope; the default filename for a requested workspace file is
`<kebab-case-solution-name>-solution.md`.

Before sharing either template's filled output, review it
for customer names, screenshots, business impact, implementation detail, and
credentials, get the builder's approval for the content and the destination,
and send only after that approval.
