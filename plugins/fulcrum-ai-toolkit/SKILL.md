# Fulcrum AI Toolkit

Use this bundle as the entrypoint for Fulcrum platform work. Select the
focused skill that best matches the request and follow its instructions:

- `skills/fulcrum-discovery/SKILL.md` for clarifying a new workflow
- `skills/fulcrum-workflow-decomposition/SKILL.md` for breaking complex
  operations into orchestrated phases
- `skills/fulcrum-app-goal/SKILL.md` for defining the desired outcome
- `skills/fulcrum-product-knowledge/SKILL.md` for platform capabilities and
  constraints
- `skills/fulcrum-app-builder/SKILL.md` and `skills/fulcrum-app-design/SKILL.md`
  for app schemas and implementation
- `skills/fulcrum-data-events/SKILL.md`, `skills/fulcrum-report-building/SKILL.md`,
  `skills/fulcrum-app-extensions/SKILL.md`, and
  `skills/fulcrum-integration-patterns/SKILL.md` for automation and custom logic
- `skills/fulcrum-gis-mapping/SKILL.md` for mapping workflows and geospatial
  behavior
- `skills/fulcrum-query-api/SKILL.md` for Query tables and read-only SQL
  workflows
- `skills/fulcrum-access-management/SKILL.md` for users, roles, permissions,
  and SSO/SCIM patterns
- `skills/fulcrum-data-migration/SKILL.md` for imports, transformations, and
  migration planning
- `skills/fulcrum-safety/SKILL.md` for governance, risk controls, and
  operational safeguards
- `skills/fulcrum-app-scorecard/SKILL.md` and
  `skills/fulcrum-performance-review/SKILL.md` for assessment and review
- `skills/fulcrum-solution-document/SKILL.md` for documenting the result

Keep the complete `skills/` directory together. The focused skills reference
one another and their supporting resources by relative path. This bundle
provides guidance only; it does not include Fulcrum credentials or register an
MCP server.
