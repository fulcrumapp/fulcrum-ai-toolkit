# Fulcrum AI Toolkit

Use this repository-root entrypoint for Fulcrum platform work. Select the
focused skill under `plugins/fulcrum-ai-toolkit/skills/` that best matches the
request and follow its instructions:

- `plugins/fulcrum-ai-toolkit/skills/fulcrum-discovery/SKILL.md` for clarifying
  the workflow and scope
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-workflow-decomposition/SKILL.md`
  for breaking complex operations into orchestrated phases
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-app-goal/SKILL.md` for defining
  desired outcomes and acceptance criteria
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-product-knowledge/SKILL.md` for
  platform capabilities and constraints
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-app-design/SKILL.md` and
  `plugins/fulcrum-ai-toolkit/skills/fulcrum-app-builder/SKILL.md` for schema
  design and implementation
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-data-events/SKILL.md`,
  `plugins/fulcrum-ai-toolkit/skills/fulcrum-app-extensions/SKILL.md`, and
  `plugins/fulcrum-ai-toolkit/skills/fulcrum-integration-patterns/SKILL.md`
  for automation and external integrations
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-gis-mapping/SKILL.md` for mapping
  workflows and geospatial behavior
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-query-api/SKILL.md` for Query
  tables and read-only SQL workflows
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-access-management/SKILL.md` for
  users, roles, permissions, and SSO/SCIM patterns
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-data-migration/SKILL.md` for
  imports, transformations, and migration planning
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-safety/SKILL.md` for governance,
  risk controls, and operational safeguards
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-report-building/SKILL.md` for
  report templates and output design
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-app-scorecard/SKILL.md` and
  `plugins/fulcrum-ai-toolkit/skills/fulcrum-performance-review/SKILL.md` for
  audits and performance reviews
- `plugins/fulcrum-ai-toolkit/skills/fulcrum-solution-document/SKILL.md` for
  implementation handoff and documentation

Keep the complete `plugins/fulcrum-ai-toolkit/skills/` directory together. The
focused skills reference one another and their supporting resources by relative
path. This bundle provides guidance only; it does not include Fulcrum
credentials or register an MCP server.
